# Highlands Coffee - Business Analysis

Đây là project phân tích nghiệp vụ cho hệ thống đặt hàng và chăm sóc khách hàng của Highlands Coffee.

Project tập trung vào việc tìm hiểu bối cảnh kinh doanh, xác định vấn đề, phân tích các bên liên quan và mô tả yêu cầu cho hệ thống.

## Nội dung chính

- Phân tích hiện trạng và nhu cầu của Highlands Coffee
- Xác định stakeholder liên quan đến hệ thống
- Mô tả yêu cầu nghiệp vụ và yêu cầu chức năng
- Xây dựng use case cho các luồng chính
- Đề xuất hướng cải thiện trải nghiệm đặt hàng và tích điểm

## Tài liệu chính

File `PTNV_TheBeTrAyer.pdf` là tài liệu phân tích nghiệp vụ của project.

Trong tài liệu có các phần chính như:

- Giới thiệu bài toán
- Phân tích stakeholder
- Phân tích yêu cầu
- Use case và mô tả luồng xử lý
- Tổng kết giải pháp đề xuất
